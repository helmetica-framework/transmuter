= Create a reagent

Check the upstream chart against the xref:references/prima-materia-checklist.adoc[prima materia checklist] first.
For a guided walk through the whole cycle, see xref:tutorials/first-reagent.adoc[Your first reagent].

[source,bash]
----
transmuter transmute \
  --name my-service \ <1>
  --prima-materia-url oci://... \ <2>
  --prima-materia-version x.y.z <3>
----
<1> The name of the new reagent. The command creates a folder with this name.
<2> URL of the upstream chart. OCI and classic Helm repositories such as `https://charts.appcat.ch/vshnpostgresql` both work.
<3> Version of the upstream chart. There is no floating tag, so an exact version is required.

The upstream chart is added as a dependency with the alias `service` in `Chart.yaml`.
The new reagent ships a pre-seeded `values.yaml` that wires up the framework's operators, see xref:ferment::explanations/values.adoc[The reagent's values.yaml].

`--ferment-url` is optional and defaults to `oci://ghcr.io/helmetica-framework/ferment`.
A ferment URL without a tag resolves to the latest available version.

The new reagent comes with a `docs/` skeleton for its end-user documentation.
Fill it in, then xref:how-tos/publish-reagent.adoc[publish the reagent].

`--path` is optional on every command that takes it and defaults to the current directory, so the other commands are meant to be run from inside the reagent.
